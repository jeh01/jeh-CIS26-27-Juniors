Absolute and Relative URLs

URL: Universal Resource Locator - otherwise known as a web address.

Absolute URLs: This is a complete URL including the transfer protocol. Example:
https://resources.zybooks.com/WebProgramming/mediumCatv1.jpg

Relative URLs: Specifies a relative path to the web resource with no scheme or host name (protocol or domain). They refer to resources based on the current web address you are in.

Section Links

A URL can point to a section, or FRAGMENT, of a document by adding a hash tag and a fragment identifier at the end of the URL

Example:
https://en.wikipedia.org/wiki/Computer_science#history

The section listed after the # refers to an ID attribute. EX:
<section id="history">

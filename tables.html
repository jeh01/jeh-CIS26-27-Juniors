HTML Tables

The Table Element

<table> - This is the element that creates an HTML Table. NOTE: HTML Tables are not used to organize data into rows and columns

Cells

Cells are a location in the table at a specific row and column. Cells are created at the intersection of a row and a column

Table Row

<tr> - An element that creates a row... in a table. Table rows are nested inside of table elements.

Table Header

<th> - The element that creates a cell containing table header information about the data contained in a specific column.

Table Data

<td> - The element that created a table cell containing table data

Table Data

<td> - This element defines a short decriptive text for the table.

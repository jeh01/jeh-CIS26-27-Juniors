HTML Containers

Container

Any element with an opening and closing tag that holds content.

<div>

A generic block container with no meaning of its own. This tag is useless without a class or ID attribute.

<span>

A generic inline container with no meaning of its own. This tag is useless without a class or ID attribute.

Block vs Inline

A block container - starts on a new line and takes up the full width of its parent element.

Semantic Elements

<article> Contains content that can stand alone outsidec of the context of the current web page.

<aside> Contains content that relates to the current web page, an example would be an advertisement, which is often in a section on the side of the page.
